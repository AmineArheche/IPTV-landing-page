# Deployment & Production Hosting Guide

StreamVault Pro is a static web application that can be deployed anywhere with zero server overhead.

## Recommended Hosting Providers

### GitHub Pages
1. Push your repository to GitHub.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, select `Deploy from a branch` and branch `main` (`/ (root)`).
4. Your site will be live at `https://<username>.github.io/<repo-name>/`.

### Vercel / Netlify
1. Connect your repository on the dashboard.
2. Deploy directly from the `main` branch.
