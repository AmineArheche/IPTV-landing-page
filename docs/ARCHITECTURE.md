# StreamVault Pro - System Architecture & Technical Specifications

## 1. Overview
StreamVault Pro is a modern, responsive web application engineered for premium IPTV service delivery.
It presents an immersive dark-mode UI with high-conversion landing flows, channel lineups, and customer support.

## 2. Design Principles
- **Visual Hierarchy:** Dark futuristic aesthetic with vibrant cyan/purple accents.
- **Glassmorphism:** CSS backdrop filters and refined border highlights.
- **Micro-Interactions:** Subtle hover transformations, live counter tickers, and smooth scroll anchors.
- **Performance:** Zero bloated dependencies, 100% vanilla JavaScript, CSS custom properties.

## 3. Component Architecture
- `index.html`: Main landing page (Hero, Stats, Channels, Features, Pricing, Reviews, FAQ, Footer)
- `style.css`: Design tokens, responsive grid system, and keyframe animations
- `script.js`: Interactive client-side interactions and modals
- `support.html`: Knowledge base, status center, and live support chat portal
- `support-chat.js`: Interactive support bot and ticket intake handler
